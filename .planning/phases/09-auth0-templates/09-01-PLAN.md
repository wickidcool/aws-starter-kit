  <name>Task 1: Create Auth0 provider component</name>
  <files>packages/create-aws-starter-kit/templates/apps/web/src/auth/auth0-provider.tsx</files>
  <action>
Create auth0-provider.tsx that wraps @auth0/auth0-react's Auth0Provider and adapts to our AuthContextType interface.

Implementation:
1. Import Auth0Provider and useAuth0 from @auth0/auth0-react
2. Import auth0Config from '../config/auth0-config'
3. Create a wrapper component that:
   - Wraps children in Auth0Provider with domain, clientId from config
   - Creates internal context that maps useAuth0() to our AuthContextType interface
   - Maps Auth0's user object to our AuthUser type (id=sub, email, emailVerified)
   - Implements signIn via loginWithRedirect(), signUp via loginWithRedirect({authorizationParams:{screen_hint:'signup'}}), signOut via logout()
   - confirmSignUp, forgotPassword, confirmForgotPassword should throw "Not supported" error (Auth0 handles these flows internally)

Pattern to follow: Match cognito-provider.tsx structure but use Auth0 SDK methods.

Key mappings:
- user.sub -> AuthUser.id
- user.email -> AuthUser.email
- user.email_verified -> AuthUser.emailVerified
- useAuth0().isAuthenticated -> AuthState.isAuthenticated
- useAuth0().isLoading -> AuthState.isLoading
- useAuth0().error -> AuthState.error

Use {{PACKAGE_SCOPE}} token for common-types import.
  </action>
