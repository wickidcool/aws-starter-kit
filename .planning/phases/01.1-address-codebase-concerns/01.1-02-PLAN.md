  <action>
Update defaultHeaders to use environment variable for CORS origin:

```typescript
const defaultHeaders = {
  'Content-Type': 'application/json',
  'Access-Control-Allow-Origin': process.env['ALLOWED_ORIGINS'] || '*',
  'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE, OPTIONS',
  'Access-Control-Allow-Headers': 'Content-Type, Authorization',
};
```

This keeps '*' as default for development but allows production to restrict origins via ALLOWED_ORIGINS env var.

Do NOT add ALLOWED_ORIGINS to CDK yet - that's infrastructure change outside this fix scope.
