<task type="auto">
  <name>Task 1: Create Cognito CDK stack template</name>
  <files>packages/create-aws-starter-kit/templates/apps/api/cdk/auth/cognito-stack.ts</files>
  <action>
Create new directory `templates/apps/api/cdk/auth/` and add `cognito-stack.ts`:

1. Import required CDK constructs:
   ```typescript
   import * as cdk from 'aws-cdk-lib';
   import * as cognito from 'aws-cdk-lib/aws_cognito';
   import * as iam from 'aws-cdk-lib/aws-iam';
   import { Construct } from 'constructs';
   ```

2. Create CognitoStack class extending cdk.Stack with props interface:
   ```typescript
   export interface CognitoStackProps extends cdk.StackProps {
     stage: string;
   }
   ```

3. Create User Pool with:
   - Name: `{{PROJECT_NAME}}-${props.stage}-user-pool`
   - signInCaseSensitive: false
   - selfSignUpEnabled: true
   - signInAliases: { email: true }
   - autoVerify: { email: true }
   - standardAttributes: email required
   - passwordPolicy: minLength 8, requireLowercase, requireUppercase, requireDigits

4. Create UserPoolClient:
   - Name: `{{PROJECT_NAME}}-${props.stage}-client`
   - authFlows: { userPassword: true, userSrp: true }
   - generateSecret: false (for SPA/mobile)
   - preventUserExistenceErrors: true

5. Export outputs as CfnOutput:
   - UserPoolId
   - UserPoolClientId
   - CognitoRegion (stack.region)

6. Add conditional Identity Pool creation:
   - Check if social login features are enabled (use {{AUTH_SOCIAL_LOGIN}} token)
   - If enabled, create basic Identity Pool with authenticated/unauthenticated roles
   - Export IdentityPoolId

Use `{{PROJECT_NAME}}` token for naming. Add MFA configuration if `{{AUTH_MFA}}` token is 'true'.

DO NOT use deprecated AdvancedSecurityMode - Cognito now uses ThreatProtection instead but it requires paid feature plans.
  </action>
  <verify>File exists and contains valid TypeScript. No syntax errors.</verify>
  <done>CognitoStack template created with User Pool, Client, and conditional Identity Pool.</done>
</task>
