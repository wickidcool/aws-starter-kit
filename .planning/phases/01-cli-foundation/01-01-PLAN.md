<task type="auto">
  <name>Task 2: Create TypeScript configuration</name>
  <files>packages/create-aws-starter-kit/tsconfig.json</files>
  <action>
Create tsconfig.json that:
- extends "../../tsconfig.base.json"
- compilerOptions:
  - outDir: "./dist"
  - rootDir: "./src"
  - module: "NodeNext"
  - moduleResolution: "NodeNext"
  - target: "ES2022"
  - declaration: true
- include: ["src/**/*"]
- exclude: ["node_modules", "dist"]

The module/moduleResolution must be "NodeNext" to work with ESM bin scripts that use hashbang.
  </action>
  <verify>cat packages/create-aws-starter-kit/tsconfig.json shows valid JSON extending base config</verify>
  <done>TypeScript config exists with ESM-compatible settings</done>
</task>
