<task type="auto">
  <name>Task 1: Implement conditional block processing</name>
  <files>packages/create-aws-starter-kit/src/generator/replace-tokens.ts</files>
  <action>
Add a `processConditionalBlocks()` function that:
1. Finds all `{{#if TOKEN}}...{{/if TOKEN}}` blocks (including comment-wrapped versions like `// {{#if TOKEN}}`)
2. For each block, checks if TOKEN value is 'true' in the tokens object
3. If 'true': removes the markers but keeps the content
4. If 'false' or missing: removes the entire block including markers

Use regex pattern to match both inline and multi-line blocks:
- Pattern: `/\/\/\s*\{\{#if\s+(\w+)\}\}[\s\S]*?\/\/\s*\{\{\/if\s+\1\}\}/g` for comment-wrapped
- Also handle plain `{{#if TOKEN}}...{{/if TOKEN}}` without comment prefix

Update the `replaceTokens()` function to call `processConditionalBlocks()` BEFORE token replacement.

Export `processConditionalBlocks` for testing.
  </action>
  <verify>TypeScript compiles: `nx build create-aws-starter-kit`</verify>
  <done>processConditionalBlocks function exported and integrated into replaceTokens</done>
</task>
