<task type="auto">
  <name>Task 1: Add auth UI to App.tsx</name>
  <files>packages/create-aws-starter-kit/templates/apps/web/src/App.tsx</files>
  <action>
Update App.tsx to include authentication UI when auth is enabled.

1. Add conditional import for useAuth hook:
```typescript
// {{#if AUTH_COGNITO}}
import { useAuth } from './auth';
// {{/if AUTH_COGNITO}}
// {{#if AUTH_AUTH0}}
import { useAuth } from './auth';
// {{/if AUTH_AUTH0}}
```

2. Inside the App function, add conditional auth state usage:
```typescript
// {{#if AUTH_COGNITO}}
const { user: authUser, isAuthenticated, isLoading: authLoading, signIn, signOut } = useAuth();
// {{/if AUTH_COGNITO}}
// {{#if AUTH_AUTH0}}
const { user: authUser, isAuthenticated, isLoading: authLoading, signIn, signOut } = useAuth();
// {{/if AUTH_AUTH0}}
```

3. Add auth UI section in the header area (after the title VStack, before Container closes):
```tsx
{/* {{#if AUTH_COGNITO}} */}
<HStack position="absolute" top={4} right={4}>
  {authLoading ? (
    <Spinner size="sm" />
  ) : isAuthenticated && authUser ? (
    <HStack>
      <Badge colorScheme="green">{authUser.email}</Badge>
      <Button size="sm" colorScheme="red" variant="outline" onClick={() => signOut()}>
        Sign Out
      </Button>
    </HStack>
  ) : (
    <Button size="sm" colorScheme="brand" onClick={() => signIn('', '')}>
      Sign In
    </Button>
  )}
</HStack>
{/* {{/if AUTH_COGNITO}} */}
{/* {{#if AUTH_AUTH0}} */}
<HStack position="absolute" top={4} right={4}>
  {authLoading ? (
    <Spinner size="sm" />
  ) : isAuthenticated && authUser ? (
    <HStack>
      <Badge colorScheme="green">{authUser.email}</Badge>
      <Button size="sm" colorScheme="red" variant="outline" onClick={() => signOut()}>
        Sign Out
      </Button>
    </HStack>
  ) : (
    <Button size="sm" colorScheme="brand" onClick={() => signIn('', '')}>
      Sign In
    </Button>
  )}
</HStack>
{/* {{/if AUTH_AUTH0}} */}
```

4. Add Spinner to the Chakra imports if not already present.

5. Make the header Box position relative to support the absolute positioned auth UI:
```tsx
<Box
  bgGradient="linear(to-r, brand.500, purple.500)"
  py={8}
  boxShadow="lg"
  position="relative"  // Add this
>
```

Note: signIn('', '') is intentional - for Cognito it would need real credentials (or redirect to Hosted UI), for Auth0 it triggers the redirect flow. Consider adding a note comment explaining this.
