## Overview

Transform the existing AWS Starter Kit into an interactive CLI tool that scaffolds new projects. Starting from CLI foundation, we built the wizard interface, template system, and generation engine, then added feature customization and polish for npm publishing.

## Milestone Summary

**Decimal Phases:**

- Phase 1.1: Address Codebase Concerns (inserted after Phase 1 to fix tech debt before templating)

**Key Decisions:**

- Use NodeNext module resolution for ESM hashbang compatibility
- Output to dist/src/ path to match Nx tsc executor behavior
- Use .template extension for project.json files to prevent Nx workspace detection conflicts
- Double-brace {{TOKEN}} syntax distinct from JS/EJS/Mustache for easy regex replacement
- Keep '*' as default CORS origin for development compatibility
- Use prompts library for interactive CLI (not inquirer or clack)

**Issues Resolved:**

- Missing handler tests for update/delete operations
- CORS hardcoded to '*' without configuration option
- Missing .env.example files for web and mobile apps

**Issues Deferred:**

- None

**Technical Debt Incurred:**

- None significant
